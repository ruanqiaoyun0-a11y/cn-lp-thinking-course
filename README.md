# 《思维学习理念复习》微课

面向 **VIPTHINK 国内线上少儿数学思维班主任（LP）** 的互动式复习微课。
帮助学员掌握核心思维理论，并能清晰、有说服力地向家长说明思维学习的重要性。

线上地址：https://ruanqiaoyun0-a11y.github.io/cn-lp-thinking-course/

---

## 课程结构（5 章）

| 章 | 主题 | 互动 |
|---|---|---|
| 1 | 什么是数学思维（思维定义 / 数学重要性 / 16 种数学方法 / 枚举法案例） | 3 道测验 |
| 2 | 学习数学思维的好处（五大好处） | 3 道测验 |
| 3 | 为什么必须重视思维培养（政策风向 / 国家战略 / 关键期） | 3 道测验 |
| 4 | 3-12 岁儿童思维发展特点（皮亚杰四阶段 / 幼儿与小学生特点） | 3 道测验 + 阶段速查库 |
| 5 | 家长沟通实战与终极考核（四大说明角度 / 表达示例） | 情境应答演练 4 个 + 终极考核选择题 3 道 |

素材来源：《思维学习理念》.pptx（25 页 · 益智国内新人训）

> 本课为**复习**定位，**不含 AI 家长对练**（原终章 AI 自由对话已按需求移除）。

## 终极考核

1. **终极考核选择题（3 题）**：覆盖向家长说明的关键要点（数学四项能力 / 四年级分水岭 / 12 岁黄金期），串行锁定、答错可重作答且不泄题
2. **情境应答演练（4 个场景）**：家长提问 → 学员用自己的话组织回应 → 关键词自检（不给标准答案）

两项全部完成（选择题 3/3 + 情境演练 4/4）即可完成课程并领取结业证书。

> 全课选择题合计 **15 道**（第 1-4 章各 3 道 + 第 5 章终极考核 3 道）。
> 终极考核原为填空题，v1.2.0 起改为选择题，与章节测验共用同一套渲染机制。

## 学习者 UI 红线

- 不显示任何阈值线 / 分数线，但展示实际得分
- 选择题答错可重新作答，且不展示正确答案
- 情境演练只给关键词命中提示与复习指引，**不给满分参考答案**

## 工程结构

```
index.html        单文件交付物（无密钥依赖）
_content.py       单一内容源（章节正文 / 题库 / 情境演练 / 速查库）
_build.py         组装 + 校验（章节数、题数、DOM 模板、AI 残留扫描）
_build.js         密钥注入（本课无 AI，自动跳过）
_server.js        本地静态服务（CDP 测试用）
_cdp_test.js      headless Chrome 全链路 E2E（90 项断言）
_run_e2e.sh       一体化 E2E（起服务 → 起 Chrome → 跑测试）
```

## 构建与验证

```bash
python _build.py                 # 组装 index.html + 校验
node --check _app.tpl.js         # JS 语法检查
bash _run_e2e.sh                 # 一体化 E2E（90 项断言）
```
